# Computer Club — frontend

Frontend учебного проекта компьютерного клуба на React, TypeScript, Vite и MUI.

## Запуск

```bash
cd frontend
npm install
npx msw init public/ --save
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). MSW перехватывает запросы `/api/computers` и `/api/computer-types` и отдаёт mock-данные из `src/mocks/data.ts`.

## Вкладки

- Dashboard — сводные карточки и первые компьютеры из MSW API.
- Компьютеры — список с поиском и фильтрами по статусу и типу.
- Сессии и История — демо-таблицы активных и завершённых сессий.
- Профиль — редактирование демо-данных пользователя.
- Администрирование — компьютеры, пользователи, сессии и статистика.
- Настройки — демонстрационные настройки уведомлений.

Операции добавления/изменения, запуск сессии и пополнение баланса пока демонстрационные и требуют подключения backend для сохранения.
